Build a modern, responsive web application prototype called **“CampusConnect – Smart Campus Companion”** based on this project idea.

### Main Goal

CampusConnect is a single platform where students register once and can discover and participate in events from their own college and other colleges. Students can view event details, faculty coordinators, venue, participation steps, register for events, earn credits, maintain participation streaks, and unlock badges/certificates.

The prototype should look like a **real working college technology platform**, not a simple static website.

### Design

* Modern futuristic college-tech UI
* Clean and professional
* Responsive for laptop and mobile
* Use a dark blue/purple/white theme with attractive gradients
* Rounded cards, subtle shadows and smooth hover animations
* Use icons for events, credits, badges, map, clubs, booking and lost & found
* Add a top navigation bar and sidebar/dashboard navigation
* Make the interface easy for first-year college students to understand

### Important Hackathon Demo Flow

The main demo should work in this order:

Landing Page → Student Registration → Dashboard → Browse Events → Open Event Details → View Faculty & Participation Steps → Register → My Events → Faculty Confirms Attendance → Credits Increase → Streak/Badge Update → Campus Map → Club → Facility Booking → Lost & Found.

Make this flow extremely smooth because the website will be demonstrated live during the hackathon.
